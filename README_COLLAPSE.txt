# Patch v3.22.196 — Πτυσσόμενη «Διαχείριση γύρων»

Βάση: v3.22.195 (ΕΑΕ dashboard / Excel) που ήδη χρησιμοποιείται.

Αρχεία αντικατάστασης (κρατήστε backup των πρωτοτύπων):
- kena-sxoleion-admin.php
- assets/vacancies.css

Λειτουργία:
- Η «Διαχείριση γύρων» είναι κλειστή κατά το άνοιγμα της σελίδας.
- Ανοίγει και κλείνει με κλικ ή πληκτρολόγιο (native HTML details/summary).
- Αν προκύψει σφάλμα σε ενέργεια διαχείρισης, εμφανίζεται ανοιχτή.
- Η επιλογή γύρου, καρτέλες Γενικής/ΕΑΕ και εξαγωγή Excel παραμένουν πάντα ορατές.
- Δεν αλλάζει ο χειρισμός υποβολών, η MySQL, το μοντέλο ή η εξαγωγή.

Έλεγχος μετά το ανέβασμα:
1. Ανανέωσε το dashboard (αν χρειάζεται Ctrl+F5 για CSS).
2. Επιβεβαίωσε ότι η «Διαχείριση γύρων» ξεκινά κλειστή.
3. Άνοιξέ την, έλεγξε ότι φαίνονται τα δύο forms, κλείσ' την.
4. Δοκίμασε αλλαγή καρτέλας Γενική/ΕΑΕ και επιλογή γύρου χωρίς αλλαγή στη βάση.

Η αλλαγή έγινε στα αρχεία του patch v3.22.195, όχι με απευθείας πρόσβαση στον live server.

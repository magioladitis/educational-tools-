# Εργαλειοθήκη Εκπαιδευτικού

Συλλογή δωρεάν εργαλείων για εκπαιδευτικούς, υποψηφίους ΑΣΕΠ, αναπληρωτές και μόνιμους εκπαιδευτικούς.

**Σχεδιασμός & υλοποίηση:** Μάριος Μαγιολαδίτης (ΠΕ03, ΠΕ86)

Κεντρική σελίδα: `ergaleia.php`

## Εργαλεία

21. `ypologismos-morion-diefthynton-ypodiefthynton-sde.php` — Μόρια επιλογής Διευθυντών & Υποδιευθυντών ΣΔΕ

## Ενημέρωση v3.17 — Ξένες γλώσσες

Στα εργαλεία 1ΕΑ/2025, 2ΕΑ/2025, 3ΕΑ/2025 και Απόσπασης στα ΔΗΜ.Ω.Σ. η γλώσσα δηλώνεται πλέον μαζί με το επίπεδό της. Η ίδια γλώσσα δεν μπορεί να δώσει διπλά μόρια: κρατείται μόνο το ανώτερο επίπεδο. ## Ενημέρωση v3.16 — Απόσπαση στα ΣΔΕ

Ο υπολογιστής `ypologismos-morion-apospasis-sde.php` εφαρμόζει τον διορθωμένο πίνακα της Υ.Α. 88422/Κ1 (Β΄ 4088/03.07.2026) μετά τη Διόρθωση Σφάλματος Β΄ 4199/10.07.2026. Η μέγιστη βαθμολογία παραμένει 40 μόρια, με κατανομή Εκπαίδευση 22, Διδακτική εμπειρία 13 και Άλλα προσόντα 5. Ο έλεγχος της ελάχιστης διετούς διδακτικής υπηρεσίας σε σχολεία Πρωτοβάθμιας/Δευτεροβάθμιας είναι ανεξάρτητος από το πεδίο της μοριοδοτούμενης τυπικής εκπαίδευσης.

## Δομή κοινών αρχείων

```text
assets/
└── common.css                  # κοινή εμφάνιση header/footer

includes/
├── config.php                  # κοινές ρυθμίσεις project
├── header.php                  # κοινή επιστροφή στην Εργαλειοθήκη
├── footer.php                  # κοινό footer/δημιουργός
├── academic-calculations.js    # κοινά ακαδημαϊκά κριτήρια
├── language-calculations.js    # κοινός έλεγχος/αποφυγή διπλομέτρησης ξένων γλωσσών
├── service-calculations.js     # κοινός υπολογισμός προϋπηρεσίας
├── sde-calculations.js         # μοριοδότηση και αντιστοίχιση ειδικοτήτων ΣΔΕ
├── sde-leadership-calculations.js # μοριοδότηση Διευθυντών / Υποδιευθυντών ΣΔΕ
└── sde-registry-calculations.js   # μοριοδότηση Μητρώου ΣΔΕ (3 κατηγορίες)
```

Τα επιμέρους εργαλεία διατηρούν το δικό τους CSS/JavaScript μόνο όταν η λειτουργία ή η εμφάνιση είναι ειδική για το συγκεκριμένο εργαλείο.

## Βασική αρχή ανάπτυξης

Τα filenames που χρησιμοποιούνται στον server και στο Git παραμένουν **σταθερά**. Προσωρινά αρχεία τύπου `-v2`, `-v3` κ.λπ. χρησιμοποιούνται μόνο για δοκιμές cache και δεν αποθηκεύονται στο repository.

Πριν από κάθε commit συνιστάται:

```bash
git status
git diff
php -l <αρχείο.php>
```

## Αποποίηση ευθύνης

Τα εργαλεία παρέχουν ενδεικτική πληροφόρηση και δεν αντικαθιστούν τις επίσημες προκηρύξεις, εγκυκλίους, αποφάσεις ή οδηγίες των αρμόδιων φορέων. Πριν από οριστική αίτηση ή ενέργεια πρέπει να ελέγχονται τα επίσημα έγγραφα.

### Κοινή λογική ΤΕ

- `includes/european-schools-calculations.js` — υπολογισμός μορίων και βασικών προϋποθέσεων Ευρωπαϊκών Σχολείων.

- `metatropi-klimakas.php`: μετατροπή βαθμού 10βάθμιας/20βάθμιας κλίμακας, δεκαδικής ή λεκτικής μορφής, με έξοδο ακέραιο μέρος/αριθμητής/παρονομαστής.

## Κοινό UI
Από την έκδοση Common UI v2, όλα τα εργαλεία μοιράζονται το ίδιο design system μέσω των `assets/common.css` και `assets/common.js`. Οι υπάρχουσες κλάσεις παραμένουν συμβατές, ενώ για νέα εργαλεία προτείνονται οι canonical `edu-*` κλάσεις που περιγράφονται στο `UI-GUIDE.md`.


### Common UI v3
The common UI now standardises the **structure** of older tools (hero, cards, fields, results and actions) while allowing each tool to retain its own colour identity. Ten legacy `app-box` pages were upgraded through the `edu-modernized` compatibility layer.

### Απόσπαση στο εξωτερικό — Παράρτημα V
Το `ypologismos-morion-apospasis-exoteriko.php` περιλαμβάνει πλέον τα μηνιαία επιμίσθια της πρόσκλησης 11771/Η2/30-01-2026. Οι έως τρεις προτιμήσεις συγκρίνονται αυτόματα ως προς το ονομαστικό μηνιαίο ποσό και εμφανίζεται ενδεικτικό 12μηνο (μηνιαίο × 12).

- Common UI v3.10: οι κάρτες «Πηγές / Νομική βάση» των legacy εργαλείων ενσωματώνονται πλέον στο κύριο container του εργαλείου για συνεπή εμφάνιση.

### v3.12 — βασικός υπολογιστής 1ΓΕ/2026 & 2ΓΕ/2026
Το `ypologismos-morion.php` έχει πλέον πραγματικό visual parity με το `ypologismos-morion-1gt-2024.php`: ίδιο hero, κάρτες, πεδία, subtotal pills, sticky αποτέλεσμα, actions και πλαίσιο πηγών. Η αλλαγή είναι UI refactor· οι υπολογιστικοί κανόνες και τα calculation modules δεν άλλαξαν.

### v3.13 — Live υπολογισμός & έλεγχος σεμιναρίου
Στον βασικό `ypologismos-morion.php` προστέθηκε έλεγχος δικαιολογητικού για την ημερομηνία έναρξης/λήξης του σεμιναρίου, χωρίς επίδραση στα μόρια. Επίσης ενοποιήθηκε η συμπεριφορά των αριθμητικών εργαλείων: τα αποτελέσματα ενημερώνονται live, ενώ τα υπάρχοντα κουμπιά «Υπολογισμός» διατηρούνται ως fallback/ρητός επανυπολογισμός.

### v3.14 — Μητρώο ΣΔΕ
Προστέθηκε το `ypologismos-morion-mitroo-sde.php`, ένας ενιαίος δυναμικός calculator για Εκπαιδευτικό Προσωπικό, Συμβούλους Ψυχολόγους και Συμβούλους Σταδιοδρομίας βάσει της Υ.Α. 75975/Κ1 (ΦΕΚ Β΄ 3224/25.06.2025). Περιλαμβάνει έλεγχο προϋποθέσεων ένταξης, αναθέσεις κλάδων, τυπικά προσόντα, επιμόρφωση, εμπειρία, γλώσσες, Η/Υ, ανεργία, ειδικές κατηγορίες και προτεραιότητα ΕΟΠΠΕΠ. Η ασυμφωνία του άρθρου 12 §2.1 (λεκτικό 12 / πίνακας 7) επισημαίνεται και το εργαλείο χρησιμοποιεί το εσωτερικά συνεπές πλαφόν 7.

### v3.15 — Ελάχιστη διάρκεια επιμόρφωσης στο Μητρώο ΣΔΕ
Διορθώθηκε ο υπολογισμός επιμόρφωσης στο `ypologismos-morion-mitroo-sde.php`: κάθε δηλωμένη επιμόρφωση διάρκειας 1–14 ωρών λαμβάνει 0 μόρια. Από τις 15 ώρες και πάνω εφαρμόζεται κανονικά ο συντελεστής 0,25 μορίων ανά 100 ώρες, με τα αντίστοιχα πλαφόν ανά κατηγορία. Ο ίδιος ελάχιστος κανόνας εφαρμόστηκε προληπτικά και στα εργαλεία απόσπασης ΣΔΕ και Διευθυντών/Υποδιευθυντών ΣΔΕ.

## Πολιτική τεκμηρίωσης

1. Νέες αλλαγές ενημερώνουν πρωτίστως το `README.md` και το σχετικό **current** αρχείο.
2. Οι παλαιές αναφορές παραμένουν στο `docs/history/`, όχι στη ρίζα.
3. Το `docs/history/` τεκμηριώνει τι ίσχυε σε παλιότερες εκδόσεις· **δεν** αποτελεί οδηγία για την τρέχουσα έκδοση.
4. Δεν μετατρέπουμε αποτυχημένη ή ανεκτέλεστη δοκιμή σε `PASS` ούτε γενικεύουμε ειδικούς νομικούς κανόνες.

Regression tests, δοκιμή PHP 7.4 και πραγματική διαδραστική δοκιμή στον browser. Οι δύο τελευταίες εξακολουθούν να αποτελούν ανοιχτά σημεία, σύμφωνα με τις αναφορές ελέγχου.

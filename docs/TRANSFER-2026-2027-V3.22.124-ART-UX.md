# Έκδοση 3.22.124 — Σύμβουλος Δικαιολογητικών Καλλιτεχνικών

- Για τις 5 κάρτες (`art-service`, `art-cv`, `art-inventory`, `art-degrees`, `art-publications`) αποσύρεται η εξωτερική προεπισκόπηση κειμένου και η περιγραφική κατηγορία. Τίτλος και checkbox παραμένουν ορατά· οι πλήρεις οδηγίες βρίσκονται στο πτυσσόμενο «Περισσότερες πληροφορίες».
- Καταργείται η ξεχωριστή εργασία `art-no-scoring` ως επανάληψη της γενικής ενημέρωσης. Δεν μεταβάλλεται η πραγματική μεθοδολογία κρίσης/μοριοδότησης.
- Η πλήρης εκτύπωση των δικαιολογητικών διατηρεί τις αναλυτικές περιγραφές όλων των υπόλοιπων στοιχείων.
- Παραμένουν εμφανείς οι σημαντικές προειδοποιήσεις προελέγχου (`art-warnings`).
- Δεν αλλάζουν νόμιμες προϋποθέσεις, απαιτούμενα δικαιολογητικά, δικαιώματα ή αριθμητικοί υπολογισμοί.

Έλεγχοι: JavaScript syntax, PHP lint, υπάρχοντες έλεγχοι Καλλιτεχνικών/Μουσικών/ΕΑΕ/Μ.Σ.Δ. και νέες δοκιμές απόδοσης HTML/εκτύπωσης.

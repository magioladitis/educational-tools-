# Μεταθέσεις μόνιμων — τρέχουσα τεκμηρίωση

**Baseline:** Εργαλειοθήκη `3.22.198`, τελευταίο dossier-audited πακέτο · ενημέρωση τεκμηρίωσης 23/10/2026.

## Αντικείμενο

Διαδικασίες μεταθέσεων μονίμων Πρωτοβάθμιας και Δευτεροβάθμιας με κοινές ενότητες: Α. τύπος διαδικασίας/υπηρεσιακά, Β. μόρια μετάθεσης, Γ. κοινωνικά κριτήρια, Δ. προσωπική λίστα δικαιολογητικών. Οι οδοί Γενικής, ΕΑΕ, ΚΕΔΑΣΥ και ειδικών σχολείων έχουν διαφορετικές προϋποθέσεις. Η εφαρμογή είναι υποστηρικτικό εργαλείο, όχι επίσημη κρίση.

## Ελεγμένα στην πρόσφατη σειρά audits

- 86/86 διαθέσιμα regression *scripts* μεταθέσεων ολοκληρώθηκαν στον τελευταίο αναφερόμενο κύκλο. Δεν σημαίνει 86 επιμέρους assertions ούτε καθολική απόδειξη ορθότητας.
- Ελέγχθηκαν επιλεγμένα σενάρια αλλαγής τύπου, εμφάνιση λίστας δικαιολογητικών, κανάλια email προς ΔΔΕ / mydocs / αυτεπάγγελτος έλεγχος / ειδικές διαδικασίες.
- Η ειδική περίπτωση συζύγου δικαστικού λειτουργού **διαφέρει** ανά βαθμίδα: στην Πρωτοβάθμια εμφανίζονται τρία δικαιολογητικά μέσω mydocs (§2.2.3), ενώ στη Δευτεροβάθμια ακολουθείται η ιδιαίτερη οδηγία αυτεπάγγελτης αναζήτησης πιστοποιητικού οικογενειακής κατάστασης.
- Οι εξαιρέσεις επανυποβολής παλιού φακέλου είναι **ειδικές**: ΕΑΕ Δευτεροβάθμιας (2025–2026) και Καλλιτεχνικά/Διαπολιτισμικά Δευτεροβάθμιας (2021–2026), μόνο όταν πληρούνται οι προβλεπόμενοι όροι και δεν προστίθενται νέα στοιχεία. Η εξαίρεση δεν αντικαθιστά τη νέα ηλεκτρονική αίτηση.
- Άγνωστος τύπος φακέλου δεν δικαιούται αυτόματη απαλλαγή από επανυποβολή.

## Ανοιχτά πριν από production sign-off

1. Πραγματικό browser smoke test σε κινητό/desktop, συμπεριλαμβανομένων αλλαγών φόρμας και εκτύπωσης.
2. Smoke test σε **PHP 7.4**, αντί της νεότερης PHP του περιβάλλοντος ανάπτυξης.
3. Περαιτέρω καθολικός νομικός έλεγχος ειδικών περιπτώσεων και παραπομπών Πρωτοβάθμιας· τα στοχευμένα audits δεν αποτελούν συνολική νομική πιστοποίηση.

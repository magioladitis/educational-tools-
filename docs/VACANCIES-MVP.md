# Καταγραφή Κενών Σχολικών Μονάδων — MVP

## Στόχος
Η εφαρμογή αντικαθιστά την αποστολή ετερόκλητων Excel με απευθείας καταχώριση ανά σχολείο. Η μη υποβολή είναι διαφορετική κατάσταση από το μηδενικό κενό. Κάθε αποθήκευση δημιουργεί νέα αναθεώρηση ώστε να υπάρχει πλήρες ιστορικό.

## Βασικό μοντέλο
- **Γύρος καταγραφής**: π.χ. «Καταγραφή 15/09/2026».
- **Υποβολή σχολείου**: πρόχειρη ή οριστική. Η ύπαρξη οριστικής υποβολής σημαίνει ότι οι μη καταχωρισμένες ειδικότητες έχουν 0 ώρες.
- **Εγγραφή ειδικότητας**: Κενό ή Πλεόνασμα + ώρες. Ο χρήστης δεν γράφει πρόσημο.
- **Αιτία μεταβολής**: νέο τμήμα, μεταβολή ωρολογίου, άδεια, μετακίνηση, διόρθωση ή άλλη αιτία.
- **Αναθεώρηση**: κάθε νέα αποθήκευση κρατά την προηγούμενη έκδοση.

## Εγκατάσταση pilot
1. Δημιούργησε MySQL βάση από το PLESK του ΠΣΔ.
2. Κάνε import το `sql/vacancies-schema.sql` και μετά το `sql/vacancies-seed-corfu-2026.sql`.
3. Αντέγραψε `includes/vacancies-config.example.php` σε `includes/vacancies-config.php` και συμπλήρωσε τα στοιχεία MySQL.
4. Για κλειστή δοκιμή μόνο, βάλε `dev_mode => true` και άλλαξε και τα δύο δοκιμαστικά κλειδιά με μεγάλα τυχαία strings.
5. Άνοιξε `kena-sxoleion-login.php`.

## Ασφάλεια / επόμενο βήμα
Το dev login είναι μόνο για κλειστή δοκιμή και δεν πρέπει να δοθεί σε σχολεία. Πριν από παραγωγική χρήση θα αντικατασταθεί από SSO ΠΣΔ και αντιστοίχιση πιστοποιημένου λογαριασμού με σχολική μονάδα/ρόλο.

## Ήδη στο MVP
- δημιουργία νέου γύρου από το admin dashboard και αυτόματο κλείσιμο του προηγούμενου ανοικτού γύρου,
- αλλαγή κατάστασης γύρου (πρόχειρος / ανοικτός / κλειστός),
- αυτόματη σύγκριση με τον προηγούμενο γύρο για τα σχολεία που έχουν οριστική υποβολή και στους δύο,
- ξεχωριστή μέτρηση ωρών που δηλώθηκαν με αιτία «δημιουργία επιπλέον τμήματος».

## Επόμενο λειτουργικό βήμα
- σύγκριση ανά ειδικότητα και αυτόματη επισήμανση αυξήσεων που δεν έχουν αιτιολογία,
- export CSV/XLSX,
- εισαγωγή των ιστορικών καταγραφών 02/09 και 15/09 ως αρχικά snapshots,
- SSO ΠΣΔ,
- σύνδεση με τον υπολογισμό διδακτικών αναγκών της Εργαλειοθήκης.

# Ανώνυμα στατιστικά χρήσης — 3.22.132

## Τι μετράμε

- **Προβολές εργαλείων**: κάθε απόκριση HTML PHP σε αναγνωρισμένο εργαλείο του επίσημου καταλόγου. Μπορεί να περιλαμβάνει ανανεώσεις, πολλαπλές επισκέψεις του ίδιου προσώπου και crawlers. **Όχι μοναδικοί επισκέπτες**.
- **Ενεργός χρόνος**: αναφορά από τον browser σε βήματα έως 30 δευτερολέπτων μόνο όσο η καρτέλα είναι ορατή, εστιασμένη και υπάρχει δραστηριότητα τα προηγούμενα 60 δευτερόλεπτα. Δεν είναι ακριβής συνολικός χρόνος συνεδρίας.
- **Μέσος ενεργός χρόνος ανά προβολή**: συνολικά ενεργά δευτερόλεπτα / προβολές. Περιλαμβάνονται και πολύ σύντομες επισκέψεις και οι επισκέψεις που επιλέγουν εξαίρεση δεν καταγράφονται.
- Η συλλογή ξεκινά από την **ημερομηνία εγκατάστασης**. Δεν υπάρχουν παλαιότερα δεδομένα.

## Πού βλέπουμε τα στοιχεία

`analytics-dashboard.php` — διαθέσιμο μόνο σε ήδη συνδεδεμένο διαχειριστή της εφαρμογής «Κενά σχολείων». Σύνδεσμος εμφανίζεται και στο `kena-sxoleion-admin.php`.

Επιλογή 7 / 30 / 90 ημερών, συγκεντρωτικά ανά εργαλείο, ημερήσια κίνηση, CSV.

## Εγκατάσταση

1. Εφαρμόστε `ergaleiothiki-3.22.132-PATCH.zip` **πάνω στην 3.22.131** ή αποσυμπιέστε την πλήρη έκδοση.
2. Συνιστάται η μεταβλητή περιβάλλοντος `EDU_ANALYTICS_DATA_DIR` να δείχνει σε υπάρχοντα, **εγγράψιμο φάκελο έξω από το public web root**. Για παράδειγμα `/home/<λογαριασμός>/private/edu-analytics`. Δεν δημιουργούμε αυτόματα ή μαντεύουμε αληθινό path server.
3. Αν δεν ρυθμιστεί, γίνεται προσπάθεια εγγραφής στο `data/_private_analytics/` της εφαρμογής. Περιλαμβάνεται προστασία μέσω `.htaccess` και προστατευμένο PHP περιεχόμενο· σε Nginx, προτιμήστε οπωσδήποτε εξωτερικό φάκελο.
4. Συνδεθείτε με λογαριασμό διαχειριστή στο «Κενά σχολείων» και ανοίξτε `analytics-dashboard.php`. Αν ο φάκελος δεν είναι εγγράψιμος, εμφανίζεται προειδοποίηση.
5. Ανοίξτε ένα εργαλείο σε δεύτερη καρτέλα, κινηθείτε σε αυτό για 30 δευτερόλεπτα και ανανεώστε τον πίνακα. Ο αριθμός προβολών και ο ενεργός χρόνος πρέπει να ενημερωθούν.
6. Ελέγξτε την **πολιτική απορρήτου** της εγκατάστασης και τυχόν απαιτήσεις νόμιμης βάσης/συγκατάθεσης πριν από παραγωγική ενεργοποίηση. Οι κανόνες διαφέρουν ανά δικαιοδοσία· ο κώδικας δεν υποκαθιστά νομικό έλεγχο.

## Ιδιωτικότητα

- Καμία τρίτη υπηρεσία στατιστικών, αναγνωριστικό χρήστη, tracking cookie, fingerprinting, διεύθυνση IP, User Agent, referrer, στοιχεία φόρμας ή query string στο αρχείο στατιστικών.
- Εγγραφή μόνο σε καθημερινά/μηνιαία αθροίσματα, με αποκλειστική πρόσβαση στο admin dashboard.
- Ο χρήστης μπορεί να πατήσει «Να μη μετριέται η χρήση μου» στη `statistika-idiotikotita.php`. Το `edu_analytics_off=1` είναι cookie προτίμησης **εξαίρεσης**, όχι αναγνωριστικό χρήστη. Η εξαίρεση ισχύει για έναν χρόνο, εκτός αν την ανακαλέσει.
- Οι HTTP headers `DNT: 1` και `Sec-GPC: 1` γίνονται σεβαστοί για pageviews και ενεργό χρόνο.
- Η υποδομή hosting ενδέχεται ανεξάρτητα να καταγράφει access logs. Η πολιτική του ιστοτόπου πρέπει να περιγράφει και αυτά.

## Ερμηνεία

Τα στατιστικά μετρούν δημοτικότητα και αλληλεπίδραση, όχι αναγκαστικά ποιότητα ή ολοκλήρωση έργου. Ένα εργαλείο εποχικής χρήσης (π.χ. μεταθέσεις, προκηρύξεις) μπορεί να παρουσιάζει εποχικές αιχμές. Για ουσιαστική αξιολόγηση αργότερα μπορούν να προστεθούν προαιρετικά ανώνυμα counters "υπολογισμός ολοκληρώθηκε" ή "έγινε εξαγωγή", χωρίς δεδομένα φόρμας.

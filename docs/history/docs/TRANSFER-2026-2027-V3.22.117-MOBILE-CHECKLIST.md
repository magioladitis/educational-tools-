# Μεταθέσεις Δ.Ε. 2026–2027 — v3.22.117: Σύμβουλος δικαιολογητικών

Αφετηρία: έκδοση **3.22.116 FULL**. Πρόκειται αποκλειστικά για βελτίωση παρουσίασης/προσβασιμότητας, χωρίς τροποποίηση στους κανόνες `build()`, στις νομικές προϋποθέσεις, στη μοριοδότηση και στην εκτυπώσιμη αναλυτική λίστα.

## Οθόνη

- Κάρτα ανά έλεγχο: checkbox, τίτλος, μικρή κατηγορία, σύντομη οδηγία και κεντρικός σύνδεσμος όπου υπάρχει.
- Κουμπί αποκάλυψης **«Περισσότερες πληροφορίες»** (native `details/summary`) για το πλήρες περιεχόμενο. Κλειστό αρχικά, εκτός από προειδοποιήσεις που αφορούν ενεργό σενάριο χρήστη.
- Σύντομες οδηγίες διατηρούν ορατές κρίσιμες ημερομηνίες, την ανάγκη οριστικοποίησης και τα ορθά κανάλια υποβολής.
- Κατάσταση ολοκλήρωσης **Χ από Υ** με `role=status`; όχι επαναλαμβανόμενη ανακοίνωση ολόκληρης της λίστας σε screen readers.
- Διατήρηση επιλεγμένων checkbox και ανοικτών πτυσσόμενων τμημάτων σε επανυπολογισμό/μεταβολή φόρμας.
- Νέα τοπικά, περιορισμένα στον υπολογιστή μετάθεσης, CSS styles. Τίτλοι καρτών 17–18px, οδηγίες 14.5–15px χωρίς γενικευμένο bold, λεπτομέρειες 14–14.5px.
- **Πηγές**: σύντομες αναφορές μέσα στα πτυσσόμενα με 12px· η τελική κοινή κάρτα πηγών ειδικά εδώ χρησιμοποιεί 15px τίτλο, 12.5px κείμενο, 12px συνδέσμους.

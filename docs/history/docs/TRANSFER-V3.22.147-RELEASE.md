# Εργαλειοθήκη Εκπαιδευτικού — Μεταθέσεις v3.22.147

## Αλλαγές από v3.22.146

1. **Μ.Σ.Δ. — τεχνικό όριο 1.000,00:** στην απευθείας εισαγωγή μορίων Μ.Σ.Δ. απορρίπτονται τιμές πάνω από 1.000,00 και αριθμοί εκτός έγκυρης μορφής (μη αρνητικός αριθμός με έως δύο δεκαδικά, κόμμα ή τελεία). Το πεδίο έχει περιορισμό μήκους 7 χαρακτήρων. Η απορριπτόμενη τιμή δεν συνυπολογίζεται στο συνολικό αποτέλεσμα· εμφανίζεται συγκεκριμένο μήνυμα επικύρωσης. **Το 1.000 είναι τεχνικό όριο προστασίας, όχι όριο μορίων θεσπισμένο από τη νομοθεσία.** Η αναλυτική εισαγωγή υπηρετήσεων παραμένει ανεξάρτητη.
2. **Έλεγχος μητρώου:** από την εγγραφή «Υπηρεσιακό μητρώο, χρόνος υπηρεσίας και Μ.Σ.Δ.» αφαιρέθηκε η δευτερεύουσα γραμμή «Έλεγχος φακέλου». Παραμένει η ήδη σαφής ένδειξη «Έλεγχος στο επίσημο μητρώο — χωρίς αποστολή».
3. **Τέκνα:** από την εγγραφή «Τέκνα — πότε απαιτούνται επιπλέον αποδεικτικά» αφαιρέθηκε η δευτερεύουσα γραμμή «Πρόσθετα μόνο εφόσον απαιτούνται». Παραμένει η ένδειξη «Αποστολή με email στη ΔΔΕ οργανικής — όπου απαιτούνται αποδεικτικά».
4. Οι δύο περιττές κατηγορίες αφαιρέθηκαν επίσης από την **εκτυπώσιμη λίστα**, χωρίς κενές γραμμές ή παρενθέσεις. Οι λοιπές ειδικές ετικέτες συνεχίζουν να εμφανίζονται.
5. **Cache/version:** `3.22.147` στο config και service worker.

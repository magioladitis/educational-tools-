# v3.22.130 — Υποδείγματα «Θέμα» / «Σώμα κειμένου»

Πηγή: εγκύκλιος ΔΕ 138014/Ε2/15-10-2026 (ΑΔΑ ΨΚΩΖ46ΝΚΠΔ-63Κ), Κεφάλαιο Α΄, §2.2.1 (Γενικές), §2.2.4 (ΕΑΕ), §2.2.5 (Μουσικά, Καλλιτεχνικά, Διαπολιτισμικά).

Η **ακριβής σειρά πεδίων** ανά περίπτωση:

- **§2.2.1 / email στη ΔΔΕ οργανικής**: Θέμα = τύπος αίτησης, αριθμός πρωτοκόλλου, αριθμός μητρώου. Σώμα = ονοματεπώνυμο, κλάδος/ειδικότητα, τύπος αίτησης, αριθμός πρωτοκόλλου, αριθμός μητρώου.
- **§2.2.4 και §2.2.5 / ΕΑΕ, Μουσικά, Καλλιτεχνικά, Διαπολιτισμικά**: Θέμα = ΔΕ, τύπος αίτησης, αριθμός πρωτοκόλλου, αριθμός μητρώου, κλάδος/ειδικότητα. Σώμα = ονοματεπώνυμο, κλάδος/ειδικότητα, τύπος αίτησης, αριθμός πρωτοκόλλου, αριθμός μητρώου, ΔΔΕ οργανικής.

Ενσωμάτωση: `includes/transfer-documents.js`, `assets/common.css`. Ο τύπος αίτησης προσδιορίζει το υπόδειγμα. Το υπάρχον `<details>` της υποβολής παραμένει το μόνο πτυσσόμενο περί αποστολής. Τα υποδείγματα τυπώνονται με την εκτύπωση δικαιολογητικών. Οι αντικαταστάσεις των αγκυλών γίνονται από τον χρήστη, με στοιχεία της οριστικοποιημένης αίτησης. Δεν απαιτούνται ή καταγράφονται στον υπολογιστή προσωπικά στοιχεία για να εμφανιστεί το υπόδειγμα.

Ιδιαίτερη προσοχή στη διάκριση προορισμών: ΔΔΕ οργανικής για δικαιολογητικά μοριοδότησης· mydocs μόνο όπου προβλέπεται για προσόντα/κριτήρια· μία αποστολή στο mydocs για Μουσικά/Καλλιτεχνικά/Διαπολιτισμικά όταν χρειάζεται νέος/συμπληρωματικός φάκελος. Ειδικές υγειονομικές γνωματεύσεις ενδέχεται να απαιτούν εμπιστευτικό ταχυδρομικό φάκελο, όχι τα παραπάνω υποδείγματα.

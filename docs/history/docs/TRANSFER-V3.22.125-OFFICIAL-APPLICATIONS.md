# Έκδοση 3.22.125 — τύποι αιτήσεων Δ.Ε. και σημειώσεις Διαπολιτισμικών

Οκτώ χωριστές επιλογές αντίστοιχες στο teachers.minedu.gov.gr: 001.ΔΕ001, 002.ΜΟΥΣ001, 002.ΚΑΛ001, 002.ΔΙΑΠ002, 003.ΔΕΒ01, 001.ΔΕΣΚΕ, 001.ΔΕΚΤ, 001.ΔΕΣΚΕ.ΚΔΣ.

Κοινή μηχανή ΕΑΕ με ειδικά στοιχεία για αισθητηριακά σχολεία (ΕΝΓ / Braille) και ΚΕΔΑΣΥ (ΠΕ02/ΠΕ03/ΠΕ04 και κενές οργανικές). Οι υπολογισμοί των ειδικών μεταθέσεων παραμένουν πληροφοριακοί. Η επιλογή τύπου αίτησης δεν δημιουργεί ούτε πιστοποιεί δικαίωμα.

Αφαιρέθηκε ο έλεγχος «Προτεραιότητα προσόντων χωρίς αριθμητική κατάταξη» για Διαπολιτισμικά. Οι ενότητες «Αλληλεπίδραση με άλλες αιτήσεις» και «Μετάθεση προς Γενική μέσα στην ίδια περιοχή» αποτελούν χωριστές σημειώσεις χωρίς checkbox και περιλαμβάνονται στην εκτύπωση.

Πηγή: 138014/Ε2/15-10-2026, Μέρος Δεύτερο, Κεφάλαια Δ΄ και Ζ΄. Επιβεβαίωση κωδικών αιτήσεων με στιγμιότυπο του συστήματος που παρέθεσε ο χρήστης.

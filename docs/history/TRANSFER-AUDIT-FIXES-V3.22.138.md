# Εργαλειοθήκη Εκπαιδευτικού — Μεταθέσεις Δ.Ε. v3.22.138

Ημερομηνία: 17/10/2026. Αφετηρία: `ergaleiothiki-3.22.137-FULL.zip`.

## Τι αλλάζει

1. **Συνολική αναγνωρισμένη υπηρεσία:** δύο ανεξάρτητοι τρόποι, όπως στις Μ.Σ.Δ. Η απευθείας εισαγωγή (έτη/μήνες/ημέρες) είναι η προεπιλογή. Η προαιρετική αναλυτική εισαγωγή αθροίζει διακριτές περιόδους και υπολογίζει τον συνολικό χρόνο· αθροίζει ημέρες πρώτα και εφαρμόζει τον κανόνα των 15 ημερών στο τελικό υπόλοιπο. Οι δύο τρόποι δεν προστίθενται μεταξύ τους. Διάρκεια άνω των 50 ετών ή άκυρες επιμέρους τιμές αποκλείουν το συνολικό αποτέλεσμα. Οι Μ.Σ.Δ. παραμένουν ανεξάρτητες.
2. **Δικαιολογητικά σε πρώτο πλάνο:** άμεσος σύνδεσμος από την πρώτη ενότητα στη λίστα και σύντομη δυναμική σύνοψη (ηλεκτρονική αίτηση, κατάλληλος τρόπος αποστολής, εξατομικευμένα σημεία ελέγχου). Διαχωρίζονται οι έλεγχοι μητρώου/αυτεπάγγελτα στοιχεία από τα δικαιολογητικά που απαιτούν ενέργεια του αιτούντος.
3. **Συνυπηρέτηση:** καθεστώς μη επιλεγμένο/«άλλη σύνθετη περίπτωση» → δεν πιστώνονται +4. Το checkbox παραμένει λειτουργικό στην αρχική επιλογή ώστε να εμφανιστεί το dropdown, ενώ οι ρητά αποκλεισμένες περιπτώσεις αποεπιλέγονται/απενεργοποιούνται.
4. **Πηγή:** Διόρθωση ΑΔΑ στη σελίδα σε `ΨΚΩΖ46ΝΚΠΔ-63Κ` (επιβεβαίωση από 1η σελίδα επίσημου PDF 138014/Ε2, παρά την ασυμφωνία στο όνομα του PDF στον ιστότοπο ΥΠΑΙΘΑ).
5. **Δικαιολογητικά ειδικής προτεραιότητας:** νέο προαιρετικό πεδίο «Ειδική κατηγορία» με χωριστές οδηγίες για Β/θμια/Ανώτατη Υγειονομική Επιτροπή (κλειστός εμπιστευτικός φυσικός φάκελος), ΚΕΠΑ (ηλεκτρονική συμπλήρωση πεδίων, όχι αποστολή γνωμάτευσης), σύζυγο δικαστικού λειτουργού (ειδική διαδικασία mydocs). Δεν υπάρχει αυτόματη απονομή προτεραιότητας. Πηγή: εγκύκλιος §§2.2.2–2.2.3.
6. **Ανάκληση και αμοιβαίες:** Προβολή 31/12/2026, 15:00 για ανάκληση αίτησης, η οποία δεν επανυποβάλλεται/ενεργοποιείται, διάκριση από ανάκληση μετάθεσης, καθώς και οδηγός αμοιβαίων εντός 15 ημερών από ανακοίνωση μεταθέσεων.
7. **Μ.Σ.Δ. και προσβασιμότητα:** εμφανής προειδοποίηση για επικαλυπτόμενες υπηρετήσεις και κοινές ημέρες, σύνδεση ετικετών με τα δυναμικά πεδία `id/for`.
8. **PWA και συμβόλαια:** έκδοση config και cache 3.22.138, ενημέρωση δύο παλαιών ελέγχων προθεσμιών που είχαν hardcoded την έκδοση 3.22.116.

## Περιορισμοί πριν την παραγωγή

- Οι λεπτομερείς υπηρετήσεις υποτίθεται ότι **δεν επικαλύπτονται**. Το εργαλείο δεν έχει ημερομηνίες έναρξης-λήξης για να εντοπίζει αυτόματα επικαλύψεις· η επιβεβαίωση γίνεται από το Μητρώο.
- Δεν κατέστη δυνατή η κανονική επίσκεψη browser στο 127.0.0.1 λόγω `ERR_BLOCKED_BY_ADMINISTRATOR`: τα browser tests χρησιμοποίησαν πιστή τοπική HTML απόδοση με inlined CSS/JS. Δεν πρόκειται για end-to-end δοκιμή του δημόσιου hosting.
- Απαιτείται smoke test στο **PHP 7.4** του παραγωγικού server (η διαθέσιμη PHP ήταν 8.4), και επανέλεγχος σε πραγματική συνεδρία browser του σχολικού hosting μετά την εγκατάσταση.
- Το εργαλείο δεν αντικαθιστά το `teachers.minedu.gov.gr`, την εγκύκλιο και την κρίση της ΔΔΕ/αρμοδίου συμβουλίου.

# Έκδοση 3.22.191 — Ενιαία εμφάνιση ενότητας Δ (δικαιολογητικά)

**Βάση:** 3.22.190 · **Ημερομηνία:** 19/10/2026

## Αλλαγές
- Δευτεροβάθμια: το `#transferDocumentsPanel` είναι τώρα κανονική `card` της Εργαλειοθήκης με το ίδιο λευκό φόντο, περίγραμμα και σκιά που χρησιμοποιούνται στα υπόλοιπα πλαίσια. Αφαιρέθηκε το inline ad hoc styling.
- Πρωτοβάθμια: οι εγγραφές του `#primaryChecklist` χρησιμοποιούν το ήδη υπάρχον κοινό σύστημα εμφάνισης της Δευτεροβάθμιας: `edu-transfer-doc`, `edu-transfer-doc__head`, `edu-transfer-doc__title`, `edu-transfer-doc__channel` και `edu-transfer-doc__disclosure`/`edu-transfer-doc__body`. Δεν αναπαράγεται δεύτερο CSS.
- Πρωτοβάθμια: ενιαία πτυσσόμενη «Περισσότερες πληροφορίες» για εγγραφές που διαθέτουν ουσιαστικές επεξηγήσεις. Οι υπάρχουσες οδηγίες συνυπηρέτησης, εντοπιότητας και τέκνων διατηρούνται. Προστέθηκαν στο ίδιο μοτίβο πληροφορίες για έλεγχο μητρώου και αυτεπάγγελτο πιστοποιητικό οικογενειακής κατάστασης.
- Η κατάσταση ανοίγματος πτυσσόμενων εγγραφών Πρωτοβάθμιας διατηρείται στον επανυπολογισμό/ανασχεδίαση.
- Αφαιρέθηκαν πλέον άχρηστα πρωτοβάθμια τοπικά CSS για τα παλιά `primary-*-guide` και `primary-doc-*`.
- Νέος εστιασμένος έλεγχος: `tests/transfer-v322191-documents-visual-parity.js`.

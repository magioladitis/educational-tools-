# Εργαλειοθήκη Εκπαιδευτικού — 3.22.175

Βάση: **3.22.174 FULL** (18/10/2026).

## Αποδεικτικά τέκνων: κοινός κώδικας Π.Ε. / Δ.Ε.

- `includes/transfer-children-documents.js`: μοναδική πηγή κειμένου και δομής για ανήλικα, σπουδάζοντα, άγαμους / διαζευγμένους γονείς και επιμέλεια, πολυτεκνία, ειδική κατηγορία αναπηρίας τέκνου, νεογέννητα, τελευταίο τρίμηνο και αυτεπάγγελτη αναζήτηση. Χωριστές τεκμηριωμένες παραπομπές για κάθε βαθμίδα.
- Πρωτοβάθμια: η προσωπική λίστα εμφανίζει πλέον αυτομάτως ενημερωτική γραμμή για τα αποδεικτικά τέκνων όταν δηλωθεί έστω ένα τέκνο, και τα αναλυτικά αποδεικτικά εμφανίζονται σε πτυσσόμενη ενότητα. Το υφιστάμενο checkbox παραμένει μόνο για ειδική περίπτωση πραγματικής αποστολής δικαιολογητικού.
- Δευτεροβάθμια: η υφιστάμενη αναλυτική και εκτυπώσιμη γραμμή αντλεί πλέον το ίδιο περιεχόμενο από κοινό αρχείο, αντί να το επαναλαμβάνει. Δεν αλλάζουν οι κανόνες υποβολής ή η μοριοδότηση.
- Ειδική κατηγορία πολυτεκνίας / αναπηρίας και συνήθη μόρια τέκνων παραμένουν ρητά διαφορετικά.
- Καμία αλλαγή σε υπολογισμούς μορίων, προθεσμίες, συνυπηρέτηση ή πρότυπα email / mydocs.

Πηγές: εγκύκλιοι 138023/Ε2 και 138014/Ε2 της 15/10/2026, Μέρος Δεύτερο «Οικογενειακοί λόγοι», Μέρος Τρίτο «Ειδικές κατηγορίες», Μέρος Πρώτο §§1.3 και 2.2.

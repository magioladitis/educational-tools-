# Εργαλειοθήκη Εκπαιδευτικού — 3.22.161

## Κοινός component κοινωνικών κριτηρίων, Π.Ε. και Δ.Ε.

**Baseline:** πλήρης 3.22.160. **Εγκατάσταση:** δοκιμαστική, όχι απευθείας παραγωγική.

### Νομικός έλεγχος

Συγκρίθηκαν οι εγκύκλιοι **138023/Ε2/15-10-2026 (Πρωτοβάθμια)** και **138014/Ε2/15-10-2026 (Δευτεροβάθμια)** ως προς το άρθρο 16 π.δ. 50/1996:

- Γάμος/σύμφωνο συμβίωσης/ειδική γονική περίπτωση: **4** μονάδες.
- Τέκνα: **4, 4, 6, 7** ανά τέκνο από το τέταρτο και μετά.
- Συνυπηρέτηση **4**, εντοπιότητα **4**, πρώτη προτίμηση **2** μονάδες, όπου πληρούνται οι όροι.
- Η πρώτη προτίμηση αφορά μετάθεση από περιοχή σε περιοχή. Οι ειδικές συνθήκες του δήμου προορισμού για ΚΕΔΑΣΥ διατηρούνται ρητά. Οι υπηρεσιακές εξαιρέσεις και οι οδοί δικαιολογητικών παραμένουν ανά βαθμίδα.

### Κώδικας

- Νέο `includes/components/transfer-social-criteria.php`: **μία πηγή HTML/PHP** για τίτλο, πλήκτρα, υπομνήματα, επιλογές συζύγου και πτυσσόμενο. Ο renderer παράγει τα αρχικά ID και το αρχικό κείμενο Δ.Ε. χωρίς διαφορά.
- Η Π.Ε. έχει τώρα την **ίδια ενότητα «Γ. Κοινωνικά κριτήρια»** με εκείνη της Δ.Ε. και διατηρεί τα δικά της ID και τις πρόσθετες υποδείξεις ΚΕΔΑΣΥ/αποδεικτικών τέκνων.
- Στην Π.Ε. η συνυπηρέτηση ελέγχεται ανά εργασιακό καθεστώς. Σύζυγος αναπληρωτής και σύμβαση Δημοσίου χωρίς οργανική **δεν μοριοδοτούνται**. Απροσδιόριστη ή αβέβαιη περίπτωση: **0 έως επαλήθευση**. Σε ΚΕΔΑΣΥ, διάθεση σε ΠΥΣΠΕ/ΠΥΣΔΕ δεν αρκεί για τεκμηρίωση οργανικής θέσης στον συγκεκριμένο δήμο.
- Η Π.Ε. υποστηρίζει στο ίδιο UI επιλογές ειδικής κατηγορίας/προτεραιότητας με ειδικές **διαφορετικές** οδηγίες: κλειστός φάκελος υγειονομικής επιτροπής, καταχώριση ΚΕΠΑ, mydocs για σύζυγο δικαστικού λειτουργού.
- Στα Διαπολιτισμικά Π.Ε. δεν εμφανίζονται κοινωνικά μόρια, γιατί δεν αποτελούν αριθμητικό κριτήριο κρίσης.
- Δεν άλλαξαν καθόλου οι δοκιμασμένοι υπολογισμοί `transfer-calculations.js`, οι κανόνες Δ.Ε. στα `transfer-ui.js`, `transfer-documents.js`, `transfer-eligibility.js`, ούτε τα emails.

### Αποτελέσματα

- **50/50** αρχεία δοκιμών JavaScript επιτυχή, μεταξύ των οποίων νέο `transfer-v322161-shared-social-regression.js` με **25** ελέγχους κοινής απόδοσης/νομικών ασφαλιστικών δικλίδων.
- **4/4** αρχεία δοκιμών Python επιτυχή.
- Δοκιμές Chromium σε πλάτη **320, 390, 768, 1280 px**, για τις δύο βαθμίδες, χωρίς JavaScript errors ή οριζόντια υπερχείλιση.
- **4/4** συγκρίσεις της ενότητας κοινωνικών κριτηρίων της Δευτεροβάθμιας πριν και μετά: **πανομοιότυπες εικόνες pixel προς pixel**.
- Δοκιμή Π.Ε.: από **38** μονάδες στις **42** μετά επιβεβαιωμένη συνυπηρέτηση, αλλά **38** όταν ο σύζυγος είναι αναπληρωτής ή λείπει επαλήθευση. Δοκιμάστηκαν και οι διαδρομές ΚΕΠΑ/mydocs.
- Το πακέτο PATCH πάνω στην ακριβή 3.22.160 πρέπει να αναπαράγει το FULL. Ο έλεγχος αυτός καταγράφεται στην τελική συσκευασία.

### Όρια

Οι τιμές είναι ενδεικτικές· η διοίκηση αποφασίζει επί δικαιώματος και δικαιολογητικών. Η Πρωτοβάθμια παραμένει πιλοτική ως προς τις μη ολοκληρωμένες κατηγορίες και ειδικές εξαιρέσεις. **Δεν έχει γίνει εγκατάσταση ή έλεγχος στον παραγωγικό PHP 7.4 server.**

# Εργαλειοθήκη 3.22.205 — μικρότερος κατάλογος, διατηρημένη προσβασιμότητα

- Αφαιρέθηκε ο μεγάλος δεύτερος σύνδεσμος «📅 Προθεσμίες» από τον κατάλογο. Η σελίδα παραμένει προσβάσιμη από την κοινή επάνω μπάρα πλοήγησης, με `aria-label` και `title`.
- Αφαιρέθηκε η ορατή επικεφαλίδα «Βρες το εργαλείο που χρειάζεσαι» και η ένδειξη «ΚΑΤΑΛΟΓΟΣ».
- Διατηρήθηκε `<h2 class="edu-tools-sr-only">Αναζήτηση εργαλείων</h2>` ως κρυφή οπτικά, αλλά προσβάσιμη σε screen reader επικεφαλίδα και όνομα της περιοχής αναζήτησης μέσω `aria-labelledby`.
- Το πεδίο αναζήτησης διατηρεί `aria-label="Αναζήτηση εργαλείου"`, χωρίς να βασίζεται αποκλειστικά σε placeholder.
- Αφαιρέθηκαν οι άχρηστοι πλέον CSS κανόνες των `toolbar-heading` και `deadline-shortcut`.
- Οι διαδικασίες μοριοδότησης και το JavaScript φιλτραρίσματος παραμένουν αμετάβλητα.
- Ενημερώθηκαν οι αντίστοιχοι ιστορικοί έλεγχοι, καθώς πλέον ο μοναδικός σύνδεσμος Προθεσμιών βρίσκεται στο κοινό μενού. Νέος έλεγχος: `tests/catalog-compact-search-v322205-contract.py`.

## Σημείωση για offline

Το `service-worker.js` και το παραγόμενο `assets/offline-registry.js` έχουν έκδοση 3.22.205 για ανανέωση cache. Το offline περιεχόμενο μπορεί να απαιτεί νέα αποθήκευση μετά την εγκατάσταση. Να γίνει δοκιμή σε Safari iPhone μετά την ανάπτυξη.

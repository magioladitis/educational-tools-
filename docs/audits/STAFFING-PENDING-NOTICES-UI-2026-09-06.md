# Staffing — contextual pending notices UI

**Ημερομηνία:** 06/09/2026

## Στόχος

Η καρτέλα 2 του `ypologismos-didaktikon-anagkon.php` δεν εμφανίζει πλέον τους εσωτερικούς μετρητές:

- `active_dependency_instances` ως «ενεργές εκκρεμείς εξαρτήσεις»,
- `active_regulatory_gap_instances` ως «περιπτώσεις κανονιστικών εκκρεμοτήτων».

Οι μετρητές παραμένουν στο backend για audit και για τη μελλοντική μηχανή κατανομής.

## Νέα συμπεριφορά

- Αν δεν υπάρχει εκκρεμότητα, δεν εμφανίζεται κανένα σχετικό UI στοιχείο.
- Για ανεπίλυτα στοιχεία Ηθικής/Θρησκευτικών εμφανίζεται μία συγκεκριμένη προειδοποίηση με τις τάξεις που επηρεάζονται.
- Άλλες dependency περιπτώσεις εμφανίζουν το συγκεκριμένο μάθημα/τάξη.
- Ένα πραγματικό `regulatory_gap` εμφανίζεται μόνο όταν είναι ενεργό στο συγκεκριμένο school profile, με το συγκεκριμένο μάθημα/τάξη και σαφή αναφορά ότι οι ώρες του εξαιρούνται από τον υπολογισμό.

## Τρέχον ενεργό scope

Στα ενεργά προφίλ Ημερήσιου Γυμνασίου και Ημερήσιου ΓΕΛ ο έλεγχος δίνει 0 ενεργά regulatory-gap instances. Τα συνηθισμένα unresolved instances όταν δεν έχουν συμπληρωθεί στοιχεία Ηθικής είναι έξι τεχνικά slots (Θρησκευτικά + Ηθική × Α΄/Β΄/Γ΄), τα οποία στο UI συμπτύσσονται σε μία κατανοητή προειδοποίηση.

## Αρχή UI

Diagnostic counters παραμένουν εσωτερικά. Ο τελικός χρήστης βλέπει μόνο πληροφορία που οδηγεί σε συγκεκριμένη ενέργεια ή εξηγεί γιατί λείπουν ώρες από τον υπολογισμό.

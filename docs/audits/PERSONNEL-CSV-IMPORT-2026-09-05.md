# Εισαγωγή προσωπικού από CSV — audit 2026-09-05

## Στόχος

Το tab **«Εκπαιδευτικοί»** του `ypologismos-didaktikon-anagkon.php` υποστηρίζει πλέον δύο ισότιμους τρόπους καταχώρισης προσωπικού:

1. χειροκίνητη προσθήκη εκπαιδευτικών,
2. μαζική εισαγωγή από CSV.

Η εισαγωγή CSV είναι αποκλειστικά client-side: το αρχείο διαβάζεται με `FileReader` στον browser και δεν αποστέλλεται στον server.

## Ροή εισαγωγής

`CSV → ανίχνευση κωδικοποίησης/διαχωριστικού → προεπισκόπηση → αντιστοίχιση στηλών → μετατροπή γραμμών → υπάρχον personnel UI → κοινός υπολογισμός ωραρίου`

Υποστηρίζονται διαχωριστικά `;`, `,` και tab. Η ανάγνωση ξεκινά ως UTF-8 και, αν προκύψουν replacement characters, επιχειρείται Windows-1253.

## Πεδία

Διαθέσιμη αντιστοίχιση για:

- Κλάδο / ειδικότητα (υποχρεωτικό mapping)
- Ονοματεπώνυμο ή χωριστά Επώνυμο + Όνομα
- Έτη / μήνες / ημέρες υπηρεσίας
- ενιαία στήλη προϋπηρεσίας
- Ρόλο
- Ώρες σε άλλη μονάδα
- Κλίμακα τμημάτων Διευθυντή/ντριας
- Κλίμακα ωραρίου ΔΕ

Οι κλάδοι κανονικοποιούνται (`PE03` → `ΠΕ03`, `ΠΕ 04.01` → `ΠΕ04.01`). Άγνωστος κλάδος δεν διορθώνεται αυθαίρετα: η εγγραφή παραμένει για χειροκίνητο έλεγχο.

## Τρόπος εφαρμογής

Ο χρήστης μπορεί να επιλέξει:

- **Προσθήκη στις υπάρχουσες εγγραφές**
- **Αντικατάσταση του προσωρινού προσωπικού**

Μετά την εισαγωγή οι γραμμές χρησιμοποιούν ακριβώς τον ίδιο live υπολογισμό υποχρεωτικού ωραρίου με τις χειροκίνητες εγγραφές. Η server-side σύνοψη ανά κλάδο ανανεώνεται με το υπάρχον κουμπί «Υπολόγισε ωράρια προσωπικού».

## Πρότυπο

Το κουμπί **«Λήψη προτύπου CSV»** δημιουργεί UTF-8 BOM, semicolon-delimited CSV ώστε να ανοίγει ομαλά σε ελληνικό Excel/LibreOffice.

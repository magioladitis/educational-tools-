# School Profile Workload Matrix — Audit 2026-09-05

## Στόχος

Να προστεθεί εσωτερικό layer που απαντά με ασφάλεια στο ερώτημα:

`συγκεκριμένο σχολείο → πραγματικά ενεργά curriculum slots → ώρες → υψηλότερη ανάθεση → επιλέξιμοι κλάδοι`

χωρίς να μετατρέπεται η κανονιστική επιλεξιμότητα σε ψευδή τελική ανάθεση εκπαιδευτικού ή σε λειτουργικό κενό.

## Υλοποίηση

Προστέθηκε:

- `includes/school-profile-workload.php`

Το αρχείο δεν φορτώνεται από:

- `anatheseis-mathimaton.php`
- `orologio-programma-mathimaton.php`

Άρα το βήμα είναι αποκλειστικά server-side και δεν αλλάζει το public UI.

## Staffing leaf codes

Η μήτρα δουλεύει με πραγματικούς leaf κλάδους του `teacher-specialties.php`.

Parent/family κωδικοί όπως:

- `ΠΕ04`
- `ΠΕ79`
- `ΠΕ87`
- `ΠΕ88`
- `ΠΕ89`
- `ΠΕ91`

χρησιμοποιούνται για κανονιστικό family matching, αλλά δεν εμφανίζονται ως ξεχωριστές staffing γραμμές όταν υπάρχουν οι επιμέρους υποκλάδοι.

## Κατηγορίες ωρών ανά κλάδο

Για κάθε κλάδο παράγονται:

- `ordered_exclusive_top_priority_hours`: ώρες όπου ο κλάδος είναι ο μόνος leaf κλάδος στην υψηλότερη διαθέσιμη Α΄/Β΄/Γ΄ ανάθεση,
- `ordered_shared_top_priority_hours`: ώρες όπου μοιράζεται την υψηλότερη Α΄/Β΄/Γ΄ ανάθεση με άλλους κλάδους,
- `special_top_priority_hours`: ώρες ειδικής κανονιστικής ανάθεσης που δεν ανήκουν στην κανονική Α΄/Β΄/Γ΄ ιεραρχία,
- `fallback_hours`: ώρες όπου ο κλάδος έχει χαμηλότερη ανάθεση από άλλον διαθέσιμο κλάδο,
- `eligible_hours_by_priority`: πλήρης αποτύπωση επιλεξιμότητας Α΄/Β΄/Γ΄/SPECIAL.

Τα shared/fallback totals μπορούν να επικαλύπτονται μεταξύ διαφορετικών κλάδων. Δεν είναι άθροισμα θέσεων.

## Ε.Ε.Ε.ΕΚ. Κέρκυρας

`readiness = structure_only`

- fixed curriculum hours: 0
- assignment units: 0

Αυτό δεν σημαίνει «μηδενικό ωράριο». Σημαίνει ότι το engine αρνείται να κατασκευάσει ώρες ανά κλάδο χωρίς αξιόπιστο section count.

## Τι ΔΕΝ κάνει ακόμη η μήτρα

Δεν υπολογίζει:

- ποιος συγκεκριμένος εκπαιδευτικός θα πάρει κάθε μάθημα,
- ποιος υπερισχύει μεταξύ ισότιμων κλάδων της ίδιας ανάθεσης,
- υποχρεωτικό διδακτικό ωράριο ανά πρόσωπο,
- διαθέσιμες/καλυμμένες ώρες από υπάρχον προσωπικό,
- πλεονάσματα ή λειτουργικά κενά.

Αυτά απαιτούν επόμενο layer με πραγματικό προσωπικό και constraints τοποθέτησης.

## Επόμενο ασφαλές βήμα

Το επόμενο layer πρέπει να δεχθεί **πραγματικό προσωπικό σχολικής μονάδας**:

`κλάδος + εκπαιδευτικός + υποχρεωτικό ωράριο + διαθέσιμες ώρες + περιορισμοί/προτεραιότητες`

και να λύσει το allocation των 216 αποκλειστικών και 137 κοινών κανονικών ωρών χωρίς να παραβιάζει Α΄/Β΄/Γ΄ ανάθεση, ειδικές αναθέσεις, dependencies ή regulatory gaps.

# Ωνάσεια / ΔΗΜ.Ω.Σ. — Φετινές λειτουργικές ανάγκες ανά ειδικότητα (R29)

Ημερομηνία: 26-08-2026
Βάση: R28

## Στόχος

Στον `ypologismos-morion-onaseia.php`, μετά την επιλογή ειδικότητας, εμφανίζονται οι λειτουργικές ανάγκες πλήρους ωραρίου για το σχολικό έτος 2026-2027, όπως καταγράφονται στις αποφάσεις 55/ΔΕΔΗΜΩΣ και 56/ΔΕΔΗΜΩΣ της 26/08/2026.

## Production αλλαγές

### 1. `ypologismos-morion-onaseia.php`

- Προστέθηκε πλαίσιο `Φετινές λειτουργικές ανάγκες ΔΗΜ.Ω.Σ. 2026-2027` κάτω από την επιλογή ειδικότητας.
- Για κάθε ειδικότητα εμφανίζονται:
  - συνολικός αριθμός θέσεων,
  - σχολικές μονάδες,
  - κωδικός σχολικής μονάδας,
  - αριθμός θέσεων ανά σχολική μονάδα.
- Για ΠΕ02, ΠΕ03 και ΠΕ04 εμφανίζεται χωριστά και η ΕΑΕ, εφόσον υπάρχουν θέσεις της 56/ΔΕΔΗΜΩΣ.
- Για ΠΕ04 προστέθηκε υποεπιλογή `ΠΕ04.01 / ΠΕ04.02 / ΠΕ04.04 / ΠΕ04.05`, αποκλειστικά για την προβολή των κενών. Δεν επηρεάζει τη μοριοδότηση.
- Για ΤΕ16 προβάλλεται η θέση μουσικής ΠΕ79.01 με ρητή επισήμανση ότι στη διαδικασία ισχύει απόλυτη πρόταξη ΠΕ79 έναντι ΤΕ16.
- Προστέθηκαν οι δύο αποφάσεις στις `Πηγές / Νομική βάση`.
- Προστέθηκε ενημερωτική επισήμανση ότι τα κενά αποτυπώνουν τις ανάγκες της 26/08/2026 και μπορούν να μεταβληθούν με νεότερη απόφαση ή μετά από τοποθετήσεις.

### 2. `includes/onaseia-vacancies-2026.js`

Νέο ετήσιο data module. Τα δεδομένα των κενών μένουν εκτός του calculator ώστε:

- να μην αναμειγνύονται με τη λογική μοριοδότησης,
- να μπορούν να αντικατασταθούν εύκολα σε επόμενο σχολικό έτος,
- να ελέγχονται ανεξάρτητα με regression tests.

Σύνολα που κωδικοποιήθηκαν:

- Γενική Εκπαίδευση: 143 θέσεις πλήρους ωραρίου.
- ΕΑΕ: 16 θέσεις πλήρους ωραρίου.

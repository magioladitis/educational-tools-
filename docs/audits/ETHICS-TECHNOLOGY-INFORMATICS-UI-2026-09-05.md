# Ηθική / Θρησκευτικά & Τεχνολογία / Πληροφορική — UI / staffing audit

Ημερομηνία: 2026-09-05

## Στόχος

Βελτίωση του frontend `ypologismos-didaktikon-anagkon.php` χωρίς αλλαγή της βασικής κανονιστικής βάσης:

1. Η ενότητα Ηθικής / Θρησκευτικών να μην επιβαρύνει οπτικά τη φόρμα όταν δεν χρειάζεται.
2. Ο ειδικός χωρισμός Τεχνολογίας / Πληροφορικής του Ημερήσιου Γυμνασίου να επηρεάζει τις πραγματικές ώρες ομάδων διδασκαλίας στο school-profile workload.

## Ηθική / Θρησκευτικά

Η ενότητα μετατράπηκε σε πτυσσόμενο `<details>` panel. Παραμένει κλειστή χωρίς δεδομένα και ανοίγει αυτόματα μετά από POST όταν υπάρχουν ήδη καταχωρισμένα στοιχεία Ηθικής. Η απουσία στοιχείων εξακολουθεί να αφήνει τα religion/ethics slots ως unresolved dependency και δεν δημιουργεί τεχνητές ώρες.

## Τεχνολογία / Πληροφορική

Κανονιστική βάση: Υ.Α. 74472/Δ2/16-06-2020, ΦΕΚ Β΄ 2450/19-06-2020.

Όταν ένα τμήμα υπερβαίνει τους 21 μαθητές/ήτριες, χωρίζεται σε δύο ομάδες.

- Α΄ Γυμνασίου: ο χωρισμός δημιουργεί πρόσθετη ομάδα για Πληροφορική, Τεχνολογία και Οικιακή Οικονομία.
- Β΄–Γ΄ Γυμνασίου: ο χωρισμός δημιουργεί πρόσθετη ομάδα για Πληροφορική και Τεχνολογία.

Το frontend ζητά μόνο πόσα κανονικά τμήματα ανά τάξη υπερβαίνουν το όριο των 21. Το backend αποθηκεύει αυτά τα τμήματα ως `technology_informatics_split_sections` και τα μετατρέπει σε `extra_course_sections`. Δεν αλλάζει το βασικό ωρολόγιο πρόγραμμα ανά μαθητή/τμήμα· αλλάζει μόνο ο αριθμός πραγματικών teaching groups για τη στελέχωση.

Οι τιμές κλειδώνονται ώστε να μην υπερβαίνουν τον αριθμό κανονικών τμημάτων της αντίστοιχης τάξης.

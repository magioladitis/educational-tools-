# Εργαλειοθήκη Εκπαιδευτικού — Μεταθέσεις v3.22.148

## Στοχευμένες αλλαγές στον Σύμβουλο Δικαιολογητικών

1. **ΚΕΔΑΣΥ:** αφαιρέθηκε ολόκληρη η επαναλαμβανόμενη εγγραφή «ΚΕΔΑΣΥ — κλάδος και προβλεπόμενη οργανική θέση» από τη λίστα δικαιολογητικών. Η επαλήθευση κλάδου/οργανικής θέσης εξακολουθεί να γίνεται στον υπάρχοντα προέλεγχο θεμελίωσης δικαιώματος. Η εκτυπώσιμη λίστα παράγεται από τις ίδιες εγγραφές, οπότε η περιττή εγγραφή δεν τυπώνεται.
2. **Συνυπηρέτηση:** αφαιρέθηκε μόνο η δευτερεύουσα ετικέτα «Δικαιολογητικά βάσει επιλογής» από τις επιλέξιμες περιπτώσεις. Παραμένουν «Δικαιολογητικά συνυπηρέτησης», η ένδειξη «Αποστολή με email στη ΔΔΕ οργανικής — όπου απαιτούνται αποδεικτικά», καθώς και οι ουσιαστικές προειδοποιήσεις «Υπό επιβεβαίωση — δεν προστίθενται +4» / «Δεν θεμελιώνεται συνυπηρέτηση (+0)» στις σχετικές περιπτώσεις.
3. **Έκδοση/cache:** ενημερώθηκαν σε `3.22.148` οι τιμές του `includes/config.php` και του `service-worker.js`.

## Επιβεβαιώσεις

- PHP syntax check και JavaScript syntax check: χωρίς σφάλματα.
- 42/42 εκτελέσιμα αρχεία regression tests μεταθέσεων: επιτυχή (συμπεριλαμβανομένου νέου ειδικού τεστ).
- Chromium σε πλάτη 320, 390, 768 και 1280 px: αφαιρούμενη εγγραφή/ετικέτα δεν εμφανίζεται, διατηρούνται οι προϋποθέσεις ΚΕΔΑΣΥ και οι οδηγίες συνυπηρέτησης, δεν προκύπτουν JavaScript errors ή οριζόντια υπερχείλιση.
- Δεν έγινε επέμβαση στην παραγωγική εγκατάσταση PHP 7.4.

## Παράδοση

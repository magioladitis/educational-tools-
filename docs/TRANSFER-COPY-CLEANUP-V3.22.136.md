# Μεταθέσεις Δ.Ε. — βελτιώσεις διατύπωσης v3.22.136

- Καταργήθηκε το μη λειτουργικό ελεύθερο πεδίο **«Κλάδος / ειδικότητα (προαιρετικά)»** από τον Φάκελο Προσόντων. Η επιλογή κλάδου για Καλλιτεχνικά και Διαπολιτισμικά χρησιμοποιεί ήδη τα αντίστοιχα dropdown με οργανικά κενά. Δεν μεταβλήθηκαν αυτοί οι έλεγχοι.
- Ο Σύμβουλος Δικαιολογητικών εξηγεί πλέον ρητά ότι η αποστολή/υποβολή των δικαιολογητικών γίνεται, ανά περίπτωση, με **email στην αρμόδια ΔΔΕ** ή **μέσω mydocs.minedu.gov.gr**. Δεν παρουσιάζονται ως ελεύθερα εναλλακτικοί τρόποι για τα ίδια δικαιολογητικά.
- Η ίδια διάκριση αποτυπώνεται στο αρχικό κείμενο του πτυσσόμενου για την αποστολή δικαιολογητικών. Οι εξατομικευμένες οδηγίες ανά τύπο αίτησης παραμένουν αμετάβλητες.
- Δεν τροποποιήθηκαν μοριοδότηση, νόμιμες προϋποθέσεις ή κατάλογοι οργανικών κενών.

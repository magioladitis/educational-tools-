## Βασικοί κανόνες

- Μία **αποδεκτή** διαδρομή προσόντων αρκεί· πολλαπλά επιλεγμένα προσόντα δεν απαιτείται να είναι όλα αποδεκτά, αλλά εμφανίζεται έλεγχος για μη επαρκές πρόσθετο προσόν.
- Η **τριετής διδακτική υπηρεσία από διορισμό** για Γενική → ΕΑΕ παραμένει ανεξάρτητη από την **πενταετή διαδρομή εξειδίκευσης ΕΑΕ**.
- Σχολεία Κωφών/Τυφλών: ελέγχεται **επιπλέον** αντίστοιχη πιστοποίηση ΕΝΓ/Braille. «Δεν έχω δηλώσει/δεν ξέρω» → κίτρινο, ρητά «δεν διαθέτω» → κόκκινο, «διαθέτω» → κίτρινο για έλεγχο γνησιότητας/φορέα.
- Για ΚΕΔΑΣΥ διατηρείται ο έλεγχος κλάδων ΠΕ02–04. Η ειδική διαδρομή ΠΕ11 αποκρύπτεται και αποεπιλέγεται μόνο εκεί.
- Ο αριθμητικός υπολογιστής μορίων παραμένει αμετάβλητος. Τα αποτελέσματα είναι προκαταρκτικά και όχι πράξη διοίκησης.
